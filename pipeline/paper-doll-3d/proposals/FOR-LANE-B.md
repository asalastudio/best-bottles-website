## 1. `extract()` never reads your Volume Absorption node — HIGH VALUE

**This is why tuning glass in Blender has never changed anything in the browser.**

`materials.py :: extract()` currently does:

```python
# attenuation is not a Principled slider, so it rides along from LIBRARY
lib = LIBRARY.get(key, {})
rec["attenuationDistance"] = lib["atten_dist"]
rec["attenuationColor"]    = lib["atten_color"]
```

It copies constants from the `LIBRARY` dict at the top of the file. So you can
move Density and Color in `materials.blend` all day, run extract, and the
browser receives **the same numbers it always had**. The authoring loop looks
connected and is not.

### The fix

The transferable quantity is the absorption COEFFICIENT:

```
Blender    sigma = density x (1 - volumeColour)
three.js   sigma = -ln(attenuationColor) / attenuationDistance
```

Same physics, different parameterisation. Read sigma out of the node, then
re-express it. Patch: `materials-extract-reads-volume.patch`

```bash
git apply pipeline/paper-doll-3d/proposals/materials-extract-reads-volume.patch
```

It also emits `absorptionCoefficient` and a `_blender` block, so the JSON
records where the values came from.

## 2. `BottleViewer.tsx` should import the shared presets — MEDIUM VALUE

There are currently **two ambers**:

| | value |
|---|---|
| `BottleViewer.tsx` inline `GLASS` table | `attenColor #a8571a`, atten `0.030` |
| `src/lib/materials/glassPresets.ts` | `attenuationColor #8b6a38`, atten `0.014` |

The second is solved from a photograph of a real 9 mL amber (IMG_5040):
measured transmission `.260/.143/.040` over a ray-cast 3.24 mm x2 wall gives
sigma `[208, 300, 497] /m`. Cobalt and frosted are measured the same way from
the product photography.

Suggested change — roughly ten lines:

```ts
import { GLASS_PRESETS, applyGlassPreset } from "@/lib/materials/glassPresets";
// then drop the inline GLASS table and read from GLASS_PRESETS
```

`applyGlassPreset(mesh, preset)` is the same call the configurator will use, so
a value approved in the Material Lab is the value the product ships.

### Worth knowing before you decide

- **frosted is neutral.** Measured `.896/.898/.899`, saturation 0.00 — frosted
  glass has essentially no volume absorption. It is clear glass with an etched
  SURFACE, so its character is almost entirely `roughness`. That is the one
  value a photograph cannot give us.
- **cobalt is lopsided.** sigma `[286, 260, 19] /m` — it blocks red and green
  almost completely and passes a narrow deep blue. Authoring it as an evenly
  absorbing blue tint is wrong.
- **amber has two candidate values** and they disagree. IMG_5040 gives
  `#8b6a38`; the older, brighter-lit catalogue shot gives `#c88e63`. The
  preset uses IMG_5040 and records the alternative rather than hiding it.
