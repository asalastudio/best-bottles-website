overwrote each other twice in `BottleViewer.tsx` and both edited

## Before you touch anything

```bash
git status          # is the tree yours?
git log --oneline -5
```

`git worktree list` shows 9 worktrees on this repo. All real work is in the
MAIN checkout on `feat/bottle-bodies-3d`. Ignore the worktrees.

## Live Blender

Only ONE session drives the running Blender at a time. Before changing a live
scene: `bpy.data.filepath` and `bpy.data.is_dirty` — if it is dirty, someone
is mid-edit; do not revert or open over it.

And when experimenting in a live file, **change one variable at a time**. On
2026-08-30 density, world, key light, ray visibility and geometry were all
changed across a few minutes, and the result could not be attributed to any
one of them. Snapshot first (`save_as_mainfile(copy=True)`), then move.
