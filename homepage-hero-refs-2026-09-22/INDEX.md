## Current homepage hero aspect ratio

Live Next.js homepage (`https://best-bottles-website.vercel.app/`) renders `data-scene="empire-niche"` — the v8 Empire fitment hero, not the water still and not a stone-platform banner.

| Surface | Native / CSS | Ratio |
|---|---|---|
| **v8 niche stage** (current default) | 3584×1024 (`/assets/hero/v8/base.webp`, `public/assets/hero/v8/manifest.json`) | **3.5:1** |
| Desktop hero box | full viewport width × **685 px** (`CollectionShopping.module.css`) | viewport-dependent: ~2.10:1 at 1440, ~2.80:1 at 1920 |
| Tablet niche | copy stacks above the scene (`max-width: 1100px`) | auto height, not a fixed ratio |
| Phone niche | overlay composition, `max-width: 640px` | compact scene, copy over left |
| **Water still** (`?hero=water`) | `hero-empire-water-rebuilt.webp` **2688×1152** | **7:3 (2.333:1)** |
| Water CSS < 1100 px | `.immersiveArt { aspect-ratio: 16/9 }` | 16:9 |
| Water CSS ≤ 640 px | `.immersiveArt { aspect-ratio: 6/5 }` | 6:5 |
| Water generation brief | GPT Image 2.5 / Sunburst | requested **21:9**; delivered 7:3 |
| Artwork-standard “homepage feature” | `docs/reviews/homepage-collections/artwork-standard.md` | **27:16** (collection/feature art, not the live hero) |
| Catalog / plate stills | 1000×1100 or 1560×1716 | **10:11** |
