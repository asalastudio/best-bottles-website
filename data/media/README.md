# 106-SKU product media reconciliation

`reconciliation-106.csv` is the stakeholder review sheet. The JSON carries the same SKU-level provenance for code and audits. All 106 component associations remain unresolved in this media-only pass; a photograph does not prove neck fit or a register assembly.

The 59 `local-source-cutout` records have exact-SKU Photoshop sources, passed extraction checks, and are available under `/images/pdp/reconciled-2026-09-27/`. Product pages and catalog cap selections can use these as interim photographs when no published plate exists. The other 47 records retain their current image fallback. They include 25 source-review cases, 7 aliases requiring identity checks, 6 recovered legacy images, and 9 Shopify-only images. Do not automatically publish those as assemblies.

The local exports are transparent WebP cutouts. The UI paints them over `#F5F3EF` with a multiply blend to suppress legacy white matte inside clear glass. This is a display treatment, not a new bottle master. The original source path and SHA-256 plus the exported asset SHA-256 are recorded per row so later Sunburst 2.5 replacements can be traced to the same exact SKU.

For the high-fidelity pass, reuse each locked bottle body and shoulder/height standard across its cap and applicator variants. Reshoot a distinct assembly only where the cap, fitment, sidecar, glass color, or source quality changes. Compare the generated result with the original source and approved family hero before replacing an interim cutout. Do not infer component compatibility from a matching thread size or filename alone.
