What we found in the Shopify store today

  1. Any order of $50 or more can pick a $0.00 "Economy" shipping rate. $50 is also the site's order minimum, so today every order can ship free.
  2. The store's shipping location has no street address or ZIP code, only "United States". FedEx can't price a parcel without the origin ZIP.
  3. All 2,635 product variants weigh 0 lb. We already hold unit and case weights for about 2,160 of them and can load them.
  4. FedEx is connected only to a test shipping profile covering 50 variants, with only "FedEx Ground Economy" switched on. No other shipping app or rate service is installed.
  5. No sales tax is collected in any state, California included.
  6. Shopify is set to ship to 27 countries using Shopify's own USPS and DHL rates.
  7. 13 products are still set to Draft and can't be bought. The store has taken one order in total, a test in May.
