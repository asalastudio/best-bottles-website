# Cap swatch coverage, 20 Nov 2026

Which cap and closure options on the catalog cards have no photo for their swatch, so the card shows a colour chip instead of the cap. Read from production (best-bottles-website.vercel.app) on 20 Nov 2026: every family's catalog page, every card, every cap option including those behind "+N". Production picks the photo with the same code as this branch (`catalogCapPhoto`), so the list holds after the swatch change.

- **1580** cap options across **19** families.
- **1061** have a photo. All 177 photos in use are measured in `cap-swatch-bounds.generated.json`, so each is cropped to the cap and shown at full swatch height.
- **519** have no photo and show a cap-shaped colour chip. They are listed below.

Photos that show the part but read less clearly at swatch size (not counted as missing):

- Droppers from the plate index include the full glass pipette, so the collar and bulb draw small.
- Vintage bulb sprayers from the plate index lie on their side (bulb, collar and tube), so they read as a small horizontal shape.
