# 28 ml and 5/8 dram hosted release

The owner requested committing and merging the current corrections on November 2, 2026. This release connects four 28 ml / 16 mm assemblies and three existing 5/8 dram vial assemblies to the hosted master system. The existing 456 recipes are preserved byte for byte after canonical serialization.

The 28 ml body follows the owner's archive PSD, including the complete neck and shoulder retouch layers. The shared metal/plastic rollers and black/white cap art retain their reviewed outlines. The vial set uses the existing approved green and cobalt photos and native cap artwork. Geometry, view placement, physical identifiers and Shopify references are unchanged by publication.

`upload-plan.json` records the exact source hashes and scope. `asset-receipt.json` records public URL, byte-hash, cache and CORS checks for the nine masters and their display copies. `display-verification.json` verifies alpha and visible RGB for all 36 lossless resized copies. `release-manifest.json` identifies the seven additions and the hash of the preserved 456 recipes. The other remaining-Cylinder candidates keep their existing local review gate.

`verify-hosted.cjs` checks every approved master API, selected desktop/mobile product states, catalog heroes, controls and the actual vial Builder. Use `QA_ORIGIN` for the exact deployment, `QA_OUT` for private evidence output, and `QA_ACCESS_FILE` only when a protected preview needs the authorized short-lived access URL. Access URLs, cookies and credentials must never enter the report or Git.

High-resolution source archives remain in the Best Bottles Drive library: [28 ml source package](https://drive.google.com/drive/folders/1Dp-9BUrdf3Z0wwXnFRtQBZa5yyajJJlm) and [5/8 dram vial source package](https://drive.google.com/drive/folders/1AwGvmJ3auRPQgmNxdBxFUkCyVP-YLTyZ).
