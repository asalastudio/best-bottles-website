# 5 ml Cylinder GPT appearance review

The recovered historical GPT clear/cobalt bare-body masters and new October 31 edits are preserved here. Originals and measured Blender v19 masters remain intact. This package does not replace product or builder artwork.

The first generated pair was rejected: its body was 7–8% too narrow at equal height, and Jordan flagged the threads. The revised pair simplifies the upper thread turns and lower neck bead using IMG_6841 as a physical reference. A subsequent width correction brings coarse body and external-thread image ratios within 0.3% of the stated targets: 53.23 mm height, 17.45 mm body, 12.60 mm thread crests. These are pixel screening checks, not certification of thread pitch, fit or glass-wall geometry. Some alpha edge artifacts remain at full resolution.

Generation used the built-in image tool. It did not expose a model identifier; this package does not label these files as Sunburst. Prompts, versions, SHA-256 hashes, before/revised images, photo reference and desktop/mobile browser evidence are included. Five image-tool outputs are preserved: first clear, first cobalt, clear thread edit, clear width correction, and revised cobalt.

Pending: owner appearance acceptance, full landmark registration, cap/roller/sprayer fit, through-glass dip-tube appearance, and then 71-SKU and builder rollout. The candidate images are not yet connected to the live local PDP or builder.
