# Cylinder 9 ml built-in material pilot

Jordan authorized the built-in image generator on November 1 after the Sunburst API pilot failed for lack of credits. One edit used the recovered clear 9 ml 17-415 body and the previously supplied clear-glass reference. The built-in tool does not expose its exact model version.

The unmodified output is a review candidate. It has real alpha and softer cylindrical highlights, but the silhouette is approximately 5.7% wider relative to its height than the source at alpha >=128. There are small residual alpha flecks above the rim and below the base. This is not ready for master approval or component integration. No additional batch was started.

The comparison shows both images at equal visible bottle height using uniform CSS scaling. The source retains its recorded 43.5% shoulder-to-foot span and 91% baseline on a 10:11 canvas. The candidate uses that same overall bottle height for visual comparison; its shoulder, neck and base registration are not approved. No pixels were stretched, retouched or replaced after generation.

Once approved and correctly registered, the same body asset, scale and anchors must feed both the product page and bottle builder. Existing masters and runtime mappings remain unchanged.
