# Approved Elegant hero release

31 Sunburst 2.5 Elegant heroes are visually approved and locked at native 2080 × 2288. Five approved local background cleanups use bone #F5F3EF; the other 26 approved aligned exports are unchanged. Glass-foot baseline is 91%, with approved shoulder-to-foot spans 39/43/47/57% for 15/30/60/100 mL. `approval.json` locks final file hashes, exact product identities and alignment measurements.

The existing `NEXT_PUBLIC_CATALOG_HERO_PILOT=families-2026-09-22` build flag includes this release with the previously approved Cylinder, Circle, Round and Empire sets. Exact SKU and filtered group matching remain required. The previous behavior is preserved with the flag off or in Cylinder-only mode. No Convex/Shopify writes or deployment were performed.

The two 30 mL matte-gold sprayers, GBElg30SpryMattGl and GBElgFrst30SpryMattGl, are not part of this release and retain their existing imagery. Their source nozzle color is approved; generation remains outstanding. This is not a claim that all 33 Elegant images are complete.

Original PSDs, material references and raw generation attempts remain in the local image workspace. Only selected final PNGs, approval evidence and tooling are committed. PNG filenames include their content hash; rollback consists of reverting the Elegant registry import without affecting the four earlier family releases.

Background finishing preserves protected bottle/hardware interiors and uses localized source shadow residuals on bone. The antialias boundary changes where needed; no additional spatial transform is applied. The five empty-background sample patches pass exact RGB(245,243,239); products and shadows are excluded. The other 26 were approved visually as sufficiently consistent, not claimed to be pixel-exact bone everywhere.
